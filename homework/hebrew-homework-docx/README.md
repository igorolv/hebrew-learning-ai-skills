# hebrew-homework-docx

Скилл для преобразования markdown-файлов с выполненными домашними заданиями по ивриту в DOCX.

## Что делает

- Принимает markdown-файл — результат работы скила `hebrew-homework-solve`
- Генерирует форматированный DOCX с правильной типографикой для иврита (David 18pt, RTL) и русского (Arial 10pt)
- Обрабатывает все типы упражнений: вставка глагола, перевод, выбор слова, классификация, текст для чтения
- Корректно обрабатывает смешанные иврит/русский строки
- Конвертирует markdown-таблицы в таблицы Word с правильными BiDi-настройками
- Проверяет структурный контракт DOCX без обязательного постраничного рендера

## Как использовать

Подключите папку как skill в используемой AI-среде либо вызовите bundled Python-скрипт напрямую.

## Структура

```
hebrew-homework-docx/
├── SKILL.md                                      — основная инструкция
├── README.md
├── scripts/
│   └── build_homework_docx.py                    — скрипт генерации DOCX
└── references/
    ├── ДЗ_урок_14_часть_1_9-13_25.md            — образец: спряжение, перевод, чтение
    └── ДЗ_урок_14_часть_1_27-29.md             — образец: антонимы, текст для чтения
```

## Входные данные

Markdown-файл — результат работы скила `hebrew-homework-solve`.

Формат имени: `ДЗ_урок_N_часть_M_слайды_X_Y.md` или `ДЗ_урок_N_часть_M.md`.

## Часть пайплайна

Этот skill — этап конвертации в пайплайне подготовки домашних заданий. Полный цикл можно
запустить через [hebrew-homework-pipeline](../hebrew-homework-pipeline).

1. [hebrew-lesson-extract](../hebrew-lesson-extract) — извлечение структуры из PPTX
2. [hebrew-lesson-enrich](../hebrew-lesson-enrich) — обогащение грамматической шпаргалки
3. [hebrew-homework-solve](../hebrew-homework-solve) — выполнение домашних заданий → markdown
4. **hebrew-homework-docx** ← вы здесь (принимает результат шага 3)

Параллельная ветка: [hebrew-lesson-docx](../hebrew-lesson-docx) — шпаргалка в DOCX (от шага 2).
