# Homework Pipeline

Формальное описание pipeline для AI-агентов. Человекочитаемое описание — в [README.md](README.md).

## Режимы запуска

Pipeline поддерживает два режима.

### Пошаговый режим

Пользователь запускает отдельные скиллы. После каждого этапа агент показывает результат и ждёт
следующего запроса. Для `hebrew-homework-solve` пользователь указывает номера слайдов.

### Полный автоматический режим

Пользователь явно вызывает `hebrew-homework-pipeline` и передаёт PPTX. Один запрос авторизует
все этапы без подтверждений между ними. Оркестратор сам выбирает все слайды категорий
`exercise_*`, `reading`, `joke`, `image_task`, создаёт обе DOCX-ветки и общую директорию результатов.

## Граф отдельных этапов

```text
PPTX урока
    |
    v
[hebrew-lesson-extract]
    |
    | урок_N_часть_M_extracted/ (md + images/)
    v
[hebrew-lesson-enrich]
    |
    | Шпаргалка_по_N_уроку_M_часть.md
    |
    +-----------------------------+
    |                             |
    v                             v
[hebrew-homework-solve]   [hebrew-lesson-docx]
    |                             |
    | ДЗ_урок_N_часть_M.md        | Шпаргалка.docx
    v
[hebrew-homework-docx]
    |
    | ДЗ.docx
```

## Полный конвейер

```text
PPTX
  |
  v
[hebrew-homework-pipeline]
  |
  +-- extract -> extracted/ (md + images/)
  +-- enrich  -> Шпаргалка.md
  +-- solve all tasks -> ДЗ.md
  +-- lesson-docx + homework-docx
  +-- collect -> урок_N_часть_M_result/
```

Оркестратор не заменяет специализированные скиллы: он вызывает их в установленном порядке
и применяет их validation gates.

## Стыки между этапами

### extract → enrich

| Поле | Значение |
|---|---|
| Артефакт | `урок_N_часть_M_extracted/` |
| Содержимое | `урок_N_часть_M_extracted.md` + `images/` |
| Формат | Классифицированные слайды: grammar, vocabulary, exercise_*, reading и т.д. |

### extract + enrich → homework-solve

| Поле | Значение |
|---|---|
| Артефакты | extracted Markdown + `Шпаргалка_по_{N}_уроку_{M}_часть.md` |
| Использование | Тексты заданий, изображения, грамматика, словарь, таблицы спряжения |
| Выбор слайдов | Пользовательский в пошаговом режиме; автоматический в `all_tasks` |

### enrich → lesson-docx

| Поле | Значение |
|---|---|
| Артефакт | `Шпаргалка_по_{N}_уроку_{M}_часть.md` |
| Выход | DOCX с тем же базовым именем |

### homework-solve → homework-docx

| Поле | Значение |
|---|---|
| Артефакт | `ДЗ_урок_{N}_часть_{M}_слайды_{СЛАЙДЫ}.md` |
| Выход | DOCX с тем же базовым именем |

## Выбор всех заданий

В режиме `all_tasks` включать:

- все `exercise_*`;
- `reading`;
- `joke`;
- `image_task`;
- слайды `other`, которые после проверки оказались заданиями.

Не включать справочные `grammar`, `vocabulary`, `conjugation`, `verb_summary`, `shem_peula`,
`numerals`, `prepositions`, если на них нет явного задания.

Номера сортировать и сжимать в суффикс: `25,26,27,30,33,34,35` → `25-27_30_33-35`.

## Внешние входы

| Вход | Пошаговый режим | Полный конвейер |
|---|---|---|
| PPTX урока | обязателен для extract | обязателен |
| Номера слайдов | обязательны для solve | определяются автоматически |
| Предыдущие шпаргалки частей 1..M-1 | опциональны | использовать, если доступны |

## Порядок выполнения

### Пошаговый

```text
1. extract
2. enrich
3. homework-solve и/или lesson-docx
4. homework-docx после homework-solve
```

### Полный

```text
1. extract + validation
2. enrich + validation
3. выбрать все задания
4. homework-solve + validation
5. lesson-docx и homework-docx + структурная проверка
6. собрать выходную директорию
```

## Поведение при ошибке

Если validation gate этапа не пройден:

1. Исправить проблему в пределах текущего workflow и повторить этап.
2. Не передавать повреждённый артефакт дальше.
3. Если исправление невозможно без пользовательских данных, остановить только зависимую ветку
   и сообщить точный недостающий вход.
4. Не маркировать частичный результат как полный конвейер.

## Конвенции именования

| Артефакт | Формат имени |
|---|---|
| Извлечённый урок | `урок_{N}_часть_{M}_extracted/` (`.md` + `images/`) |
| Извлечённый урок Markdown | `урок_{N}_часть_{M}_extracted.md` |
| Шпаргалка | `Шпаргалка_по_{N}_уроку_{M}_часть.md` |
| Домашнее задание | `ДЗ_урок_{N}_часть_{M}_слайды_{СЛАЙДЫ}.md` |
| DOCX | то же базовое имя, `.md` → `.docx` |
| Полный комплект | `урок_{N}_часть_{M}_result/` |

Все выходные файлы создавать в рабочей директории пользователя, не в репозитории скиллов.
