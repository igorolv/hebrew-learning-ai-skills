# hebrew-homework-pipeline

Скилл-оркестратор полного цикла обработки урока иврита.

## Что делает

По одному PPTX-файлу последовательно:

1. извлекает структуру урока и изображения;
2. создаёт грамматическую шпаргалку;
3. находит и решает все упражнения, тексты и задания;
4. создаёт DOCX шпаргалки и домашнего задания;
5. собирает все результаты в общую выходную директорию.

## Когда использовать

Использовать по явному запросу «обработай урок целиком», «запусти весь конвейер» или
«сделай шпаргалку и реши все задания». Для одного этапа использовать соответствующий
специализированный скилл.

## Вход

PPTX-файл урока иврита, обычно `שיעור N חלק M.pptx`.

## Основной результат

Директория `урок_{N}_часть_{M}_result/`, содержащая extracted Markdown с изображениями,
шпаргалку MD/DOCX и решённое домашнее задание MD/DOCX.
