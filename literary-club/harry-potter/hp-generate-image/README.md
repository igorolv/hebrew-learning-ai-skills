# hp-generate-image

Skill для генерации готовой книжной иллюстрации к странице ивритского Гарри Поттера.

## Что делает

- Принимает translated markdown от `hp-translate` и целевой номер страницы
- Извлекает главу из имени файла и нужный блок `# Страница N`
- Использует иврит и полный подстрочник как источник событий страницы
- Извлекает визуальные детали персонажей, локации и атмосферу
- Требует соответствия всех видимых персонажей эталонам из chapter style
- Выбирает учебно значимый ракурс с минимальной визуальной узнаваемостью
- Разрешает видимые лица, включая лица второстепенных персонажей на заднем плане
- Ограничивает только одинаково подробные групповые портреты нескольких сильно узнаваемых главных персонажей
- Использует скрывающие ракурсы только при необходимости
- Требует, чтобы любой видимый текст в иллюстрации был только на иврите
- Формирует внутренний промт в стиле традиционной книжной иллюстрации (ink + watercolor, 1990s)
- Вызывает доступный генератор изображений
- Сохраняет готовую иллюстрацию как `HP_ch{CHAPTER}_page_{PAGE}.png`
- Учитывает формат A4 (иллюстрация в верхней половине страницы)
- Включает строгие запреты (photorealism, магическое свечение, anime и т.д.)

## Как использовать

### В Claude.ai (Projects)
Добавьте файл `SKILL.md` в Project Knowledge вашего проекта.

### В Claude Code
Скопируйте папку в директорию skills и подключите через конфигурацию.

## Структура

```
hp-generate-image/
├── SKILL.md    — основная инструкция
└── README.md
```

## Входные данные

1. `master_style_framework.md` — глобальный стиль иллюстраций (приоритетный документ)
2. `BOOK_{N}_CHAPTER_{M}_STYLE.md` — описание персонажей, локаций и сцен главы (результат работы `hp-chapter-style`)
3. `HP_ch{CHAPTER}_{FROM}_{TO}_translate.md` — результат `hp-translate`
4. `PAGE` — целевая страница из диапазона translated-файла

## Выходные данные

Один готовый PNG-файл:

```text
HP_ch{CHAPTER}_page_{PAGE}.png
```

Например: `HP_ch1_page_36.png`.

## Часть проекта

Этот skill объединяет translated markdown с визуальным стайлгайдом:

1. [hp-translate](../hp-translate) — содержание страниц и учебный перевод
2. [hp-chapter-style](../hp-chapter-style) — визуальный стайлгайд главы
3. **hp-generate-image** ← вы здесь (создаёт готовый PNG)
