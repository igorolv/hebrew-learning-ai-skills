# hp-extraction

Claude Skill для извлечения ивритского текста из PDF-исходника «Гарри Поттера» и сборки в структурированный markdown.

## Что делает

- Подготавливает изображения страниц из PDF или ZIP-архива (скрипт `prepare_pdf.py`)
- Визуально читает ивритский текст с изображений
- Сохраняет буквальное совпадение базовых букв, слов и пунктуации с изображением — без исправления опечаток и реконструкций по смыслу
- Выполняет обязательную повторную визуальную сверку без перерендеринга страницы
- Сверяет Unicode ивритского слоя с реальными контурами глифов David; подтверждённый слой использует как источник точного базового написания, но не порядка и никуда
- Сохраняет оригинальные огласовки (никуд) и форматирование
- Извлекает таблицы сложных слов
- Собирает основной markdown и отдельный протокол неуверенных чтений, опечаток источника и контрольных сверок

## Как использовать

### В Claude.ai (Projects)
Добавьте файл `SKILL.md` в Project Knowledge вашего проекта.

### В Claude Code
Скопируйте папку в директорию skills и подключите через конфигурацию.

## Структура

```
hp-extraction/
├── SKILL.md                — основная инструкция
├── README.md
├── scripts/
│   └── prepare_pdf.py      — подготовка изображений из PDF/ZIP
└── references/
    └── HP_ch1_20_25.md     — образец результата (страницы 20–25)
```

## Зависимости

- Python 3
- `pymupdf` — устанавливается автоматически скриптом при первом запуске
- `fonttools` — устанавливается автоматически для глифовой проверки
- Системный шрифт David или путь к нему в переменной `HP_DAVID_FONT`

## Пример задания
